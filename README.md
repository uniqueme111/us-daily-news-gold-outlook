# 从美国新闻预测 黄金涨跌

一个平台无关的 Research Skill：实时研究美国新闻，生成中文要闻，并从实际利率、美元、避险需求、通胀和流动性等路径给出黄金的条件式研判。

## 特点

- 不依赖私有网关、内部服务或指定 API
- 可使用运行环境已有的网页搜索、浏览器、新闻聚合、RSS 或其他 Research 工具
- 覆盖政治、经济与市场、军事与外交、科技与 AI、民生与社会
- 新闻均要求附实际检索到的原文链接
- 黄金结论限定为带条件的「偏多 / 偏空 / 中性」，不提供投资建议

## 安装

将本仓库下载或克隆到 Skills 目录，并保持文件夹名为 `us-news-gold-research`：

```text
skills/
└── us-news-gold-research/
    └── SKILL.md
```

## 使用示例

- 今日美国要闻
- 美国最近有什么大事？
- Research 今天的美国新闻，并判断黄金偏多还是偏空
- 根据最近 24 小时美国政治和经济新闻分析黄金市场含义

## 运行要求

运行环境需要具备至少一种实时网页研究能力。如果无法联网，Skill 会明确说明无法核验当期新闻，而不会使用模型记忆冒充实时结果。

## 免责声明

本 Skill 仅用于新闻研究和条件式市场分析，不构成投资建议。
